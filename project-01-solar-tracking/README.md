# Solar Light Tracking System

## What It Is

A solar light tracking system that automatically adjusts the position of a solar panel according to the direction of the strongest light source.

## How It Works

The system uses Light Dependent Resistors (LDRs) to detect the intensity of light from different directions. A microcontroller compares the light readings and controls servo motors to adjust the position of the panel toward the stronger light source.

## Tools & Technologies

- Arduino
- LDR sensors
- Servo motors
- Microcontroller
- C / C++
